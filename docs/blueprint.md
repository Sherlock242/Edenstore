# **App Name**: EdenStore

## Core Features:

- Product Browsing: Allow users to browse anime t-shirts by category, popularity, or newest releases.
- Product Details: Display detailed information for each t-shirt, including images, description, size, color options, and customer reviews.
- Shopping Cart: Enable users to add items to a shopping cart, review their selections, and proceed to checkout.
- Secure Checkout: Provide a secure checkout process where users can enter shipping addresses and payment information.
- Order Tracking: Allow users to track the status of their orders.
- AI-Powered Recommendations: Offer personalized t-shirt recommendations based on browsing history and purchase behavior, using an AI tool.
- Wishlist: Allow users to save their favorite shirts to a wishlist for later purchase.

## Style Guidelines:

- Background color: Dark gray (#121212) for a modern, sleek feel.
- Primary color: Vibrant purple (#A020F0) to reflect hi-tech aspects.
- Accent color: Electric blue (#7DF9FF) for highlighting interactive elements and calls to action.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text, to give the app a computerized yet modern aesthetic.
- Use clean, modern icons that complement the hi-tech aesthetic. The icons must have high contrast against the dark background.
- Maintain a clean and organized layout, prioritizing easy navigation and visual appeal.
- Subtle animations for transitions and interactions to enhance the user experience.
